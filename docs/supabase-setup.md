# Отдельная база для разработки: что нажать

Зачем это нужно. Сейчас все три предыдущие версии продукта настроены на один и тот же боевой Supabase. Любой запуск старой папки пишет в живые данные, а тестовая генерация или выданный на пробу ключ смешиваются с настоящими. Пока платящих клиентов нет, цена ошибки нулевая — поэтому разделить базы надо именно сейчас, а не после первой продажи.

Итог: два независимых проекта Supabase. Один для разработки, где можно ломать что угодно. Второй — боевой, куда попадает только проверенное.

## Шаги

1. Откройте панель Supabase и войдите под тем же аккаунтом, где лежит текущий проект: <https://supabase.com/dashboard>

2. Нажмите создание нового проекта — кнопка «New project» в списке проектов.

3. Заполните:
   - **Name** — `neuroizium-dev`. Имя видно только вам, но по нему потом отличать проекты
   - **Database Password** — нажмите генерацию пароля и **сразу сохраните его** в надёжном месте. Этот пароль понадобится для выгрузки базы, и посмотреть его позже нельзя, только сбросить
   - **Region** — ближайший к вашим пользователям. Из доступных для России обычно разумнее всего Франкфурт
   - **Plan** — бесплатного тарифа для разработки достаточно

4. Дождитесь создания проекта — это занимает пару минут.

5. Откройте настройки проекта, раздел с API-ключами (Project Settings → API). Оттуда нужны два значения:
   - **Project URL** — адрес вида `https://xxxxxxxx.supabase.co`
   - **anon public** — публичный ключ

6. Пришлите мне оба значения или впишите сами в файл `.env` рядом с `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Это не секреты: публичный ключ задуман открытым, доступ к данным ограничивает защита на уровне строк в самой базе.

7. Отдельно сохраните строку подключения к базе (Project Settings → Database, раздел Connection string). Она нужна скрипту выгрузки `scripts/backup-db.ps1`. **Вот это уже секрет** — в файлы проекта её вписывать нельзя.

## Чего пока делать не нужно

Ключи AI-моделей, пароль администратора и секрет вебхука понадобятся на этапах 2 и 3. Их зададим в разделе секретов Edge Functions, и в код они не попадут. До этого момента приложение работает без них.

## Названия кнопок

Панель Supabase периодически меняет оформление, и подпись может немного отличаться от описанной. Смысл шагов при этом остаётся тем же: создать второй проект, забрать адрес и публичный ключ, сохранить пароль базы. Если название на экране не совпадает — пришлите скриншот, разберёмся по нему.
