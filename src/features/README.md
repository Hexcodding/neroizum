# features/ — сценарии

Один сценарий — одна папка: генерация плана, профиль бренда, экспорт, редактирование поста, активация доступа.

Внутри сценария принято делить так: `model/` — состояние и хуки, `service/` — бизнес-логика без React, `ui/` — компоненты сценария. Сервис можно вызвать из теста, не поднимая интерфейс, — именно поэтому логика не живёт внутри компонентов.
