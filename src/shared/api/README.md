# shared/api/ — транспорт

Здесь и только здесь происходит обращение к серверу: вызовы Edge Functions, клиент Supabase, разбор ответов и приведение технических ошибок к понятным сообщениям.

Транспорт не знает бизнес-правил: он не решает, можно ли клиенту генерировать план, и не считает лимиты. Компоненты сюда не обращаются напрямую — только через сервисы сценариев.
