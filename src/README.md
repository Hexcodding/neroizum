# src/ — клиентский слой

Зависимости идут строго вниз. Каждый слой может обращаться только к тем, что ниже него:

```
app → pages → widgets → features → entities → shared
```

Нарушение — ошибка линтера, а не замечание на код-ревью.

| Слой | Что здесь лежит | Чего здесь не бывает |
|---|---|---|
| `app/` | Точка входа, маршруты, провайдеры | Бизнес-логики |
| `pages/` | Страницы: только композиция из виджетов | Запросов, вычислений, состояния |
| `widgets/` | Крупные самостоятельные блоки: календарь, студия поста, форма | Знания о том, на какой странице блок стоит |
| `features/` | Сценарии: генерация плана, профиль бренда, экспорт | Вёрстки страниц |
| `entities/` | Модели предметной области: пост, план, бренд, доступ | React, маршрутизации, любых импортов из интерфейса |
| `shared/ui` | Дизайн-система | Бизнес-правил |
| `shared/lib` | Утилиты | Обращений к сети |
| `shared/api` | Транспорт: вызовы серверных функций | Бизнес-правил |

Компонент никогда не обращается к транспорту напрямую: путь всегда `компонент → хук → сервис → транспорт`.

Импорты внутри `src/` — через псевдоним `@/`, по нему сразу видно слой. Путь вида `../../lib/utils` линтер запретит.
