# entities/ — модели предметной области

Пост, контент-план, профиль бренда, площадка, доступ. Типы и чистые функции над ними: расчёт дат публикации, проверка длины текста под площадку, подсчёт пропорций типов контента.

Здесь нет React и нет ничего из интерфейса — это проверяется линтером. Смысл ограничения простой: если однажды придётся менять фреймворк, предметная логика переедет без изменений, потому что она про контент-планы, а не про кнопки.
