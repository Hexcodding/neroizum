# server/generation/ — ядро генерации

Путь от запроса до готового плана. Слой не знает, кто его вызвал: HTTP-обёртка, проверка доступа и лимиты появятся отдельно на этапе доступов.

## Порядок работы

1. **Проверка запроса.** `validateGenerationRequest` из общего словаря. Не прошло — `INVALID_REQUEST` с указанием полей, к модели запрос не уходит.
2. **Расписание.** Даты, количество постов и площадки считаются кодом.
3. **Резерв квоты.** До генерации только резерв, не списание.
4. **Части по восемь постов.** Каждая следующая знает предыдущие, поэтому не повторяет темы. Прогресс отдаётся наружу через `onProgress`.
5. **Вызов модели** через каскад: не ответила первая модель — идём к следующей, временные сбои повторяем с нарастающей паузой.
6. **Разбор ответа.** Оборванный JSON не теряется: целые посты достаются по одному.
7. **Раскладка по слотам.** Дата, номер и площадка берутся из расписания, даже если модель вернула своё.
8. **Проверка качества** по тем же правилам, что заданы в промпте.
9. **Один тихий перезапрос** проблемных постов — пользователь этого не видит.
10. **Подтверждение квоты** — только после успеха.

## Что нельзя ломать

**Квота списывается после успеха.** Резерв, генерация, подтверждение. Любой сбой освобождает резерв. В третьей версии списание шло до генерации, и каждая ошибка модели стоила клиенту генерации.

**Наружу не уходит ни одного технического слова.** Все сообщения для человека собраны в `errors.ts`, каждое отвечает на два вопроса: что случилось и что делать. Техническая причина остаётся в логах.

**Проверка качества опирается на те же данные, что и промпт.** Список тизерных фраз, лимиты площадок, пропорции типов берутся из промпт-модуля, а не переписываются здесь заново.

**Расписание — источник правды.** Номер, дата и площадка поста не зависят от ответа модели.

## Тесты без сети

`__fixtures__/fake-provider.ts` читает расписание прямо из промпта и отвечает постами на те слоты, которые в нём перечислены. Поэтому тесты проверяют настоящую сборку промпта и настоящую раскладку ответа, а не заготовленную заранее строку. Сетевых запросов в тестах нет.
