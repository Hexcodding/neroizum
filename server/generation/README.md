# server/generation/ — оркестрация генерации

Единственный путь генерации в продукте — этот. Тариф «свой ключ» выведен за рамки MVP именно для того, чтобы второго пути не существовало.

Что здесь появится на этапе 2: каскад моделей (основная не ответила — тихо уходим на запасную), до трёх повторов с нарастающей паузой на временных ошибках, спасение оборванного JSON (вытаскиваем целые посты вместо падения), проверка качества результата с одним автоматическим перезапросом проблемных постов, стриминг с возможностью остановиться и сохранением уже готового.

Правило про квоту: слот резервируется до генерации, списывается после успеха. При сбое квота остаётся у клиента.
