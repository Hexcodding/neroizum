# server/db/ — база данных

Миграции и запросы. Каждая миграция — отдельный файл с датой в имени, применяется один раз и не переписывается задним числом.

Базовые требования: защита на уровне строк включена на всех таблицах; привилегированные функции доступны только служебной роли; клиент не может изменить себе лимиты, счётчики или права администратора.

Базы для разработки и для боевой версии — разные. В предыдущих версиях все три поколения писали в один и тот же боевой Supabase, и любой запуск старой версии менял живые данные.
