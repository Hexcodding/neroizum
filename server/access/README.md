# server/access/ — доступы и лимиты

Регистрации в продукте нет: администратор выдаёт лицензионный ключ, клиент вводит его один раз.

Требования к реализации на этапе 3: ключ хранится только как хеш и показывается администратору один раз; видимый номер клиента формируется независимо от ключа и не раскрывает ни одного его символа; одна активная сессия на ключ; ограничение попыток на активации; единый ответ об ошибке, по которому нельзя понять, существует ключ или нет.
