# server/ — серверный слой

Здесь живёт всё, что не должно попасть в браузер: промпт, вызовы AI-провайдеров, проверка доступов, админские операции, работа с базой.

## Два правила, которые нельзя нарушать

**Ни одного импорта React или чего-либо из `src/`.** Проверяется двумя способами: `tsconfig.server.json` компилирует эту папку без библиотеки DOM, поэтому обращение к `window`, `document` или типам React не соберётся; линтер отдельно запрещает импорты React по имени.

**Клиент не импортирует ничего отсюда.** Особенно из `prompt/`. Линтер запрещает такие импорты, а `npm run check:bundle` после сборки ищет в готовом бандле характерные фразы промпта и роняет проверку, если находит.

## Папки

Импортировать отсюда можно только `@contracts/...` — общий словарь, о котором клиент и сервер обязаны договориться дословно. Всё остальное серверный слой держит у себя.

| Папка | Ответственность |
|---|---|
| `prompt/` | Сборка системного промпта из блоков, версионирование. Главный актив продукта |
| `generation/` | Оркестрация генерации: каскад моделей, повторы, спасение неполного ответа, проверка качества |
| `access/` | Лицензионные ключи, сессии, лимиты с резервированием слота |
| `admin/` | Выдача и продление доступов, журнал действий администратора |
| `db/` | Миграции и запросы |

Код Edge Functions запускается в Deno на стороне Supabase. Поэтому здесь нет зависимостей от Node и нет импортов из `node_modules` — только стандартные веб-API и явные внешние адреса модулей.
